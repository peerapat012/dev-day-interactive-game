# Distinguish anonymous from signed-in quiz hosts

The quiz host flow treats an anonymous session as a guest host: `getQuizAuthUser` returns a user only when an Email + Password session exists (`provider === "email"`), so `account.get()` succeeding on an anonymous session does not count as signed in. On entering quiz host, a signed-out host sees an auth gate offering "Continue as guest" or "Log in / register"; the same form is reused inside "My saved decks". Because Appwrite forbids creating a session while another is active ("Creation of a session is prohibited when a session is active"), login and register first end the current session, and `ensureGuestSession` re-checks for an active session instead of caching a one-time promise, so logging out leaves a working guest session.
